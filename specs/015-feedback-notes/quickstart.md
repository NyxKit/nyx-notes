# Quickstart: Feedback Center

## Goal

Verify the new feedback entry point, the shared note/image editor flow, and the admin review experience.

## Steps

1. Start the backend and frontend using the project’s standard local development commands.
2. Sign in as a regular user and open Feedback from the bottom-left menu.
3. Submit a feedback item with a title, description, at least one image, and a feedback type.
4. Confirm the modal closes and the current page remains visible.
5. Sign in as an admin and open Feedback again.
6. Confirm the masonry overview appears and existing feedback items can be opened in a note-style detail view.
7. Confirm admin users can add, edit, and comment on feedback items.

## Expected results

- Regular users can submit feedback without leaving their current context.
- Admins can review feedback in a vault-like overview.
- Images are preserved for both notes and feedback items.
